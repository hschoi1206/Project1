# 체중·허리 기록 (PWA)

일별 체중과 허리둘레를 기록하고 추이를 그래프로 보는 오프라인 웹앱입니다. 광고와 외부 추적 코드가 없습니다.

## 기능
- **기록:** 날짜별 체중(kg)·허리둘레(cm)·메모. 저장하면 입력칸이 비고 그날 기록 카드에서 수정·삭제합니다. 빈 칸으로 저장하면 기존 값은 유지됩니다.
- **홈:** 최근 값과 7일/30일/365일 변화
- **차트:** 일간(7일 평균), 주간(5주·20주 평균), 월간(5개월·20개월 평균), 체중·허리(상관도표). 일·주·월은 선 또는 캔들(양봉 붉은색 = 증가, 음봉 푸른색 = 감소)로 볼 수 있습니다.
  - 두 손가락으로 기간 확대·축소, 한 손가락으로 이동, 두 번 탭하면 처음 보기
- **내 정보:** 키·생년월일·성별, BMI(대한비만학회 기준), WHtR(허리 ÷ 키, 0.5 이상 주의). [저장]을 눌러야 반영됩니다.
- **투약 비교:** 위고비/마운자로 투약자는 시작일을 입력하면 임상시험 평균(투약군·위약군)과 체중 변화율을 비교합니다.
  - 위고비: STEP 1 (세마글루타이드 2.4mg, 68주)
  - 마운자로: SURMOUNT-1 (티르제파타이드 15mg·5mg, 72주)
  - 최종값은 논문 수치이고 중간 주차 값은 근사값입니다. 참고용이며 의학적 판단 근거가 아닙니다.
- **백업:** 내보내기와 불러오기는 CSV(`date,weight_kg,waist_cm,memo`, 엑셀에서 열림)입니다. 같은 날짜는 파일 값으로 덮어쓰고 파일에 없는 칸은 유지합니다.

- **초기화:** 내 정보 맨 아래 [모든 기록 삭제]. 확인창에 `초기화`를 입력하면 기록과 내 정보를 모두 지웁니다.

## 데이터
기기 브라우저의 `localStorage`(`weightTracker.v1`)에만 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 기록도 지워지므로 가끔 내보내기로 백업하세요.

## 사용 안내
친구에게는 `https://hschoi1206.github.io/Project1/weight/guide.html`을 보내면 됩니다. 설치 방법과 기능 설명이 있고, 앱 [내 정보] → [사용 안내 보기]로도 열립니다. 설명서의 앱 화면 사진은 예시 데이터로 찍은 것입니다.

## 설치 (Android)
1. Chrome으로 `https://hschoi1206.github.io/Project1/weight/` 열기
2. 메뉴 ⋮ → **앱 설치** (또는 홈 화면에 추가)

## 개발
- `core.js`: 화면과 무관한 계산(집계, 이동평균, 상관, BMI, 임상 비교, 백업 변환)
- `index.html`: 화면과 그래프
- 테스트: `node --test 'weight/tests/*.test.js'`
- 수정 후 배포할 때는 `sw.js`의 `CACHE` 이름 숫자를 올려야 설치된 앱에 새 버전이 반영됩니다.
